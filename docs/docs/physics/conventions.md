# Conventions

> Stub (P01.T08). The full specification is written in P02.T02.

The electromagnetic torque of a non-salient PMSM in the rotor (dq) frame:

### EQ-CONV-01 — Torque constant {/* #eq-conv-01 */}

$$
T = \tfrac{3}{2}\, p\, \lambda_m\, i_q = K_t\, i_q, \qquad K_t = \tfrac{3}{2}\, p\, \lambda_m
$$

where $p$ is the number of pole pairs and $\lambda_m$ is the peak phase flux linkage of the magnets [Wb].
